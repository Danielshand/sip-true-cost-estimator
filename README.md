# SIP True Cost Estimator

Single-page calculator comparing the total delivered cost of building with structural insulated panels (SIPs) against conventional stick framing. Enter a ZIP code, square footage, and basement type; every assumption is editable and cited.

Built for the Structural Insulated Panel Association (SIPA). Directional estimate based on industry averages; actual supplier pricing varies.

One self-contained HTML file, no build step. Only external dependency: Chart.js via CDN.
